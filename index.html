Bubble Bounce – Begär radering av data

Den här sidan gäller appen Bubble Bounce, utvecklad av Makolli.

Vilken data lagras?

Appen sparar följande data i Supabase:

  • Det namn eller nickname som spelaren själv skriver in
  • Spelarens poäng
  • Leaderboard‑placering

Begär radering av din data

Om du vill att ditt namn och dina poäng ska tas bort från leaderboarden kan du begära radering via e‑post:

makolli1984@gmail.com

Skriv vilket namn du vill radera så tar vi bort det från Supabase inom 48 timmar.

Lagringsperiod

Data lagras tills spelaren begär att den raderas.
